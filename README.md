# MulCLIP project page preview

A static, metadata-driven demo for the MulCLIP NeurIPS 2026 project page.

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Camera-ready update

Update `content/project.js` with final author, affiliation, public link, contact, and BibTeX metadata. The page renders changeable project information from that file. Do not move or publish anything from `references/`.
